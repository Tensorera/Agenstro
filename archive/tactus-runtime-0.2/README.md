# Frozen Tactus 0.2 Python surface

This directory preserves the removed worker, cell protocol, Jupyter bridge,
and embedded-Motivo integration points as migration evidence. The generated
Motivo JavaScript asset bundle is intentionally omitted from Git; the
maintained Electron/React source remains under `motivo-studio/`. This archive
is not a Python package, is not included in the Tactus 0.3 wheel or editable
import path, and is not a release or test gate.
