# ICMJE-2026 — ICMJE Recommendations

- 来源：https://www.icmje.org/recommendations/
- 版本：2026-01 更新
- 访问日期：2026-07-27
- 性质：ICMJE 官方建议的本地摘要，医学外稿件仅作通用参考。

ICMJE 建议覆盖署名与贡献、利益冲突、同行评审责任、研究参与者保护、科学不端与
更正、临床试验注册和数据共享，以及标题页、摘要、引言、方法、结果、讨论、参考
文献、表图等稿件组成。其目标是准确、清楚、可复现且尽量无偏的学术报告。医学或
临床要求只适用于相应研究类型；自动审查应检查声明与报告是否可见，不得在缺少投稿
表单或机构材料时断言作者未履行程序。
