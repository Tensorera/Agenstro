# ELSEVIER-REVIEW — Elsevier guide for conducting a review

- 来源：https://www.elsevier.com/reviewer/how-to-review
- 访问日期：2026-07-27
- 性质：出版商官方公开页面的本地审查摘要。

Elsevier 的结构化指导覆盖标题、摘要、引言、方法、结果、讨论、参考文献和整体
评价。核心检查包括：研究目的是否清楚；数据分析是否合适；统计报告是否需要置信
区间、效应量或敏感性分析；结论是否由数据和研究设计支持；局限是否充分；参考文献
是否相关且更新；方法是否可复现；语言和结构是否清楚。指导同时要求意见具体、有
依据、保持事实性和专业性，避免人身评论、推测作者动机及不当强迫引用。
