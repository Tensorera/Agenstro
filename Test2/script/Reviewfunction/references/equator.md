# EQUATOR-REPORTING — EQUATOR reporting-guideline principles

- 来源：https://www.equator-network.org/about-us/what-is-a-reporting-guideline/
- 访问日期：2026-07-27
- 性质：EQUATOR Network 官方说明的本地摘要。

报告指南是按明确方法开发的清单、流程图或结构化文本，用来列出特定研究类型应报告
的最少信息，使研究可理解、可复核并可用于后续证据综合。常见映射包括随机试验
CONSORT、观察性研究 STROBE、系统综述 PRISMA、诊断研究 STARD、动物研究 ARRIVE、
定性研究 COREQ/SRQR 等。审查时必须先识别研究设计，再选择相应指南；不能对不匹配
的稿件机械套用领域专用清单。
