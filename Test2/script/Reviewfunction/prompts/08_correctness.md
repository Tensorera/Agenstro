# 正确性审查核查清单

- 选取支撑摘要和结论的中心主张，反向追踪到方法、方程/证明、实验设置、图表和
  数值证据，检查内部逻辑是否闭合。
- 检查符号定义、量纲、边界条件、推导跳步、定理适用前提、统计检验解释、分母与
  样本数、百分比和表图数值是否前后一致。
- 检查比较是否同条件、结论是否由实际实验/分析覆盖，是否把缺少证据当作阴性
  证据，或把相关关系写成因果关系。
- 对无法从 PDF/OCR 可靠辨认的公式和图表明确标记，不可猜测。没有代码、原始数据
  或外部文献时，只能做可审计的内部一致性审查，不能声称已独立复算或复现。
- 发现潜在错误时给出最短验证路径，例如需要作者补充哪一步推导、哪组原始数值或
  哪项稳健性检查。
