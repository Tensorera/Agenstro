# 可复现性审查核查清单

- 以“另一支合格团队能否在不询问作者的情况下重建研究”为问题，检查数据、材料、
  代码、协议、软件/硬件版本、依赖、随机种子、参数、预处理、运行顺序和计算资源。
- 检查数据与代码可用性声明是否存在、链接/标识符是否明确、访问限制是否解释，
  版本是否冻结，结果表图是否能映射到生成步骤。
- 对实验研究检查重复次数、校准、批次、样本分配和误差；对计算研究检查环境、
  训练配置、拆分、模型选择和脚本；对理论研究检查完整定义、算法与证明细节。
- 根据稿件类型选择合适的报告指南检查项。报告“未说明”与“已说明但不可执行”
  的差别，并给出最小复现包清单。
- 本任务不实际运行代码或访问外部链接；链接存在不等于内容已验证。不得声称已经
  成功复现。
