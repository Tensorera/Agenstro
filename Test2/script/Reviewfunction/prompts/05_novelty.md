# 创新性审查核查清单

- 提取作者明确或隐含的创新主张，分别归类为新问题、新方法、新数据/资源、新理论、
  新发现、新应用或增量改进。
- 对每项主张建立“与稿件所述最近相关工作相比，新增了什么”的证据链，检查贡献
  是否具体、可辨别且由结果兑现。
- 区分技术新颖性、科学重要性、实证扎实度和潜在影响；不要用一个维度替代另一个。
- 查找夸大的 first/novel/unprecedented 等表述、只组合既有组件、仅在新数据集上
  重复验证，或贡献与相关工作比较不足的情形。
- 本任务不联网，不能证实全球首创。若稿件的相关工作不足以判断新颖性，应降低
  confidence 并给出需要作者补充的明确比较，而不是断言“没有创新”。
