# NATURE-CRITERIA — Nature editorial criteria

- 来源：https://www.nature.com/nature/for-authors/editorial-criteria-and-processes
- 访问日期：2026-07-27
- 性质：官方公开页面的本地审查摘要，不是目标 venue 的默认硬性规则。

Nature 对原创研究的公开标准强调：工作应报告原创科学研究，具有突出的科学重要性，
并得出能引起跨学科读者兴趣的结论。编辑初筛还会考虑稿件是否适合其读者以及概念
推进程度。使用本摘要时，应把“原创性”“科学重要性”“跨学科兴趣”分开评价，
不能因为方法正确就自动推断影响力足够，也不能在未指定目标期刊时把 Nature 标准
当成投稿门槛。
