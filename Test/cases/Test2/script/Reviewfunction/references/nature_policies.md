# NATURE-POLICIES — Nature Portfolio editorial policies

- 来源：https://www.nature.com/nature/editorial-policies
- 访问日期：2026-07-27
- 性质：官方政策索引的本地审查摘要。

政策主题包括署名、利益冲突、保密、研究伦理、图片完整性、抄袭与重复发表、资金
声明、AI 使用、临床研究以及数据/材料/代码/协议的报告标准。伦理审查应根据研究
实际类型选择相关项目，区分稿件内缺失、投稿系统另行提供和当前无法观察三种状态。
相似、遗漏或图像异常只能作为需编辑核查的信号，不能由自动审查直接认定不端。
