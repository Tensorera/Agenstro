# COPE-REVIEW — COPE ethical guidelines for peer reviewers

- 来源：https://members.publicationethics.org/sites/default/files/cope-ethical-guidelines-peer-reviewers-v2_0.pdf
- 访问日期：2026-07-27
- 性质：COPE 官方伦理指南的本地摘要。

COPE 指南强调只有在具备专业能力、能及时完成且不存在影响公正性的利益冲突时接受
审稿；稿件与审稿过程应保密，不得利用未发表信息谋取个人利益。报告应客观、建设性，
以证据支持，不得包含敌意或贬损语言。引用建议必须出于真实学术理由。发现疑似重复
发表、抄袭、数据操纵或其他伦理风险时，应把具体证据保密报告给编辑，而不是直接
公开指控或自行调查定案。
