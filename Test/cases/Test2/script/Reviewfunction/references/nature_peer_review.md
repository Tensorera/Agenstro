# NATURE-PEER — Nature peer-review criteria

- 来源：https://www.nature.com/nature/editorial-policies/peer-review
- 访问日期：2026-07-27
- 性质：官方公开页面的本地审查摘要。

Nature 的公开说明把可接受论文概括为：推进领域理解、可能影响领域思考，并以有力
证据支持结论。公开的决定理由包括专门性过强、缺乏新颖性、概念推进不足，以及
重大的技术或解释问题。审查时应明确区分证据强度、技术有效性、解释是否成立和
概念贡献，说明判断理由，并避免把编辑最终决定伪装成审稿人的确定结论。
