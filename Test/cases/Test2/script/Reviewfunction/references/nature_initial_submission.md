# NATURE-INITIAL — Nature initial-submission guidance

- 来源：https://www.nature.com/nature/for-authors/initial-submission
- 访问日期：2026-07-27
- 性质：官方公开页面的本地审查摘要。

公开指南要求作者注意稿件组成、报告透明度、伦理与数据/代码相关声明。对于以自定义
代码支撑中心结论的研究，指南强调在方法中给出代码可用性说明；相关研究领域还需要
报告摘要或相应清单。形式审查应检查材料在稿件中是否可见，但应承认某些投稿表单或
补充材料可能不在当前 PDF 中。除非 review_context 指定目标 venue，不应把这些
Nature 专属提交细节直接判作违规。
