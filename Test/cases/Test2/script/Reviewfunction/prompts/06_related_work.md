# 相关工作审查核查清单

- 检查文献是否覆盖问题背景、最接近的方法、关键竞争方案、基础理论和近年进展，
  并与稿件的核心贡献直接相连。
- 检查引用是否放在实际支持的陈述之后，是否出现二手引用冒充原始来源、成组引用
  无法对应主张、只罗列不比较、忽略反例或过度自引的信号。
- 对作者声称的差异建立比较维度：问题设定、假设、数据、方法、指标、成本、适用
  边界。指出缺少哪一种比较会妨碍创新性判断。
- 只能核查稿件内可见的参考文献元数据和叙述一致性；没有原文时不得判定某篇外部
  文献“被错误引用”，应写成需要作者/编辑核对。
- 不强制推荐审稿人自己的文献，也不凭常识编造具体新增引文。
