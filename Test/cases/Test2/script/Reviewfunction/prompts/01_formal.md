# 形式审查核查清单

- 识别稿件类型，并检查标题、摘要、关键词、正文层级、参考文献、图、表、公式、
  补充材料和声明区是否齐全、编号是否连续、交叉引用是否可追踪。
- 检查摘要是否自洽地覆盖目的、方法、主要结果和局限；标题是否准确描述内容。
- 检查篇幅与各部分比例是否显著失衡。未指定目标期刊时只报告可观察事实，不能
  自创字数、图表数或版式上限。
- 核对双盲匿名风险：作者名、单位、邮箱、致谢、自引措辞、基金号、文件元数据或
  数据库链接是否可能暴露身份。只有 review_context 要求双盲时才判定为违规。
- 列出缺失的投稿材料或声明，但把“稿件内缺失”与“可能另行提交、当前不可见”
  分开。PDF 视觉信息和 OCR 有冲突时明确记录。
