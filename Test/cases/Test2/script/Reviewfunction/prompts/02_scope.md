# 范围审查核查清单

- 用稿件证据归纳核心研究问题、学科主题、方法、贡献类型和预期读者。
- 若 review_context 给出目标 venue 和 scope，逐条做“匹配/部分匹配/不匹配/
  信息不足”分析，并引用 context 中的具体规则。
- 若未给出 venue，只评估其对综合性期刊、专业期刊或会议的相对适配层级，并将
  venue-specific verdict 标为 not_assessable；不得把 Nature、Elsevier 等
  通用参考摘要冒充目标期刊规则。
- 区分“主题超出范围”“受众过窄”“影响力不足”和“研究质量问题”，不要相互
  替代。指出可通过重写定位解决的问题与无法靠写作改变的范围错配。
