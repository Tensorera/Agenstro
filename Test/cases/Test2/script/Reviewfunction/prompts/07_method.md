# 方法审查核查清单

- 判断研究设计是否能够回答研究问题：对象/样本、数据来源、纳排标准、对照、
  随机化/盲法、测量、变量定义、预处理、统计或计算流程是否合理。
- 检查关键假设、混杂因素、偏差来源、数据泄漏、选择偏差、功效/样本量、缺失值、
  多重比较和敏感性分析。只要求与稿件研究类型相关的项目。
- 对实验/计算研究核对训练与测试隔离、基线公平性、超参数选择、评价指标、重复
  次数与不确定性；对理论研究核对定义、前提、适用域和证明路线。
- 区分“方法本身不合理”和“方法可能合理但报告不足”。每个主要意见说明它会
  威胁哪一类有效性，以及最小可接受修复。
- 若可识别研究类型，建议作者对照相应报告指南；不能因为无法识别就随意套用
  CONSORT、PRISMA 等领域专用标准。
